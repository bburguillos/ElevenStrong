# Sports by the Numbers: Soccer Manager v1

A classroom-ready Streamlit soccer management game with probabilistic actions, coaching choices, fatigue, substitutions, and CSV match report.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy to Streamlit Community Cloud

1. Create a GitHub repository.
2. Upload `app.py` and `requirements.txt` to the **root** of that repository.
3. In Streamlit Community Cloud, choose the repo and set the main file to `app.py`.

The rosters and ability ratings are **fictional**; all match events are generated by a transparent, classroom-oriented probability model, not official soccer data. Match statistics are real data generated within the simulation.

## Gameplay

- Pick a club, shape, and tactic; click Start Match.
- Each turn presents an attacking or defensive decision; compare probabilities.
- Choose an action to advance the clock and update the score/statistics.
- Change tactic or make substitutions during play.
- Review match report and download the event log CSV at full time.

No API keys or extra image assets required.
